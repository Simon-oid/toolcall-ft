# test_hand7 — written by Simone knowing the v5 defect (it sometimes replies instead
# of calling when a call is needed) and that test_hand6 found it. This set measures
# multi-step and multi-turn tool use in general, not only that defect; the episodes
# cover routine chains, context resolution, and correct abstention equally.
# Written without opening any training data, evaluation code, model outputs, or
# test_hand6 results. No episode here duplicates one from test_hand5 or test_hand6.
# Format: src/toolcall/handset_mt.py. One message per line, blank line between episodes:
#   E | label   U | user   c | history call   s | history reply
#   C | scored call   r | tool result (\n = newline)   A | facts the final reply must contain
# A is checked by substring (case-insensitive). "48 kB" does not match 48000;
# use any: 48000; 48,000 when multiple surface forms are acceptable.
